Verify before you run

Every release is accompanied by SHA256SUMS and a detached PGP signature SHA256SUMS.asc. Don't trust binaries that don't verify against our release key.

1. Get the verification script (one-time):

$ curl -O https://0trustvpn.com/verify-release.sh
$ chmod +x verify-release.sh

2. Download the release bundle:

$ mkdir 0.1.0 && cd 0.1.0
$ curl -O https://0trustvpn.com/releases/0.1.0/SHA256SUMS
$ curl -O https://0trustvpn.com/releases/0.1.0/SHA256SUMS.asc
$ curl -O https://0trustvpn.com/releases/0.1.0/pubkey.asc
$ curl -O https://0trustvpn.com/releases/0.1.0/0trust-0.1.0-linux-amd64

3. Verify:

$ ../verify-release.sh
# [✓] PGP signature valid (key: DEADBEEF...REPLACE-ME)
# [✓] key fingerprint matches expected: DEADBEEF...REPLACE-ME
# [✓] all 5 files match SHA256SUMS
# [✓] VERIFIED.  Safe to run.

Our release-signing key

PGP fingerprint (also available via /.well-known/security.txt and on keys.openpgp.org):

DEADBEEF DEADBEEF DEADBEEF DEADBEEF DEADBEEF DEADBEEF

Verify this fingerprint out-of-band before trusting it — check it against our published canary, Mastodon/Bluesky posts, and any in-person introduction. A fingerprint from this page alone isn't enough if you're worried about a compromised TLS chain.

Reproducible builds

The binaries are built with go build -trimpath -buildvcs=false -ldflags "-s -w" from a tagged source rev. Two builds of the same source with the same Go version produce byte-identical binaries. See build-info.txt in the release directory for the exact rev and toolchain.
