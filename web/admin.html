Node enrolment token

Lets a RAM-only node register itself. Shown once. Uses 1 is a one-shot token: fine for a box you will never restart. Anything higher pins the token to the first node's public IP and lets that node rejoin after a reboot — which it needs, because its disk is RAM and a reboot loses its key.

Outstanding tokens

Anything that can still put a node into the mesh. Revoking one leaves the node it already registered running — it holds its own PSK — but stops it re-registering.
